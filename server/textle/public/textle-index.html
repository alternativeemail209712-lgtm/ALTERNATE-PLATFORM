Word length

letters

Each new round picks a random length in this range — 4 to 15 letters by default, up to 20 letters if you want (still filtered by the difficulty tier below).

Difficulty

Scored on word familiarity, letter structure, and puzzle ambiguity — not just obscure vocabulary. "Random" skips scoring entirely and draws from every word of that length. Very short/long word lengths may not have every tier available.

Color shades

Choose how strong the green, yellow and gray of the colored segments and the keyboard look. Ten shades per color, from lightest to darkest (the middle one is the standard look). It applies right away - no new round needed - and every screen connected to this game changes together.

Win celebration

After a win, the leaderboard pops up automatically, then closes on its own. Auto-continue (above) always waits for this celebration to finish before starting the next round.

Starter word

On (default): one random word is placed on the board for free at the start of each round (worth no points) so chat has first segment clues (green / yellow / gray boxes) to read. Off: every round starts on a blank board. Takes effect from the next round; your choice is remembered.

Strict fit

On (default): a guess must still agree with the segment clues (green / yellow / gray boxes) of every guess on the board; otherwise it is skipped with the message below. Off: any real word is accepted and colored, so chat can probe freely (for example, test whether a letter appears twice). Your choice is remembered and applies right away.

Auto-color keyboard keys

On (default): every key on the keyboard takes the color its letter has earned on the board. Off: the keys stay plain (neutral) - viewers only read the colors on the tiles. Applies right away on every connected screen and is remembered.

Guess rejection message

Shown briefly whenever a guess is skipped - for example when Strict fit is on and the guess disagrees with an earlier clue.

Word length, difficulty, auto-continue and this delay only take effect once you tap Apply. Win-celebration duration applies right away.

    How to play

    • Guess the hidden word. Its length is a secret and changes every round. Your guess can be any real word, shorter or longer than the answer, so use them to test letters. Unlimited guesses, anyone can play, anytime.
    • Every guess is cut into colored segments:
      • green letters match and their order corresponds to the hidden word — letters that sit side by side in both words share one box.
      • yellow letters match, but need to be rearranged to fit the order of the hidden word.
      • gray letters are not in the hidden word (or every copy of them is already used).
    • A green segment at the very start or end of the word gets a rounded edge when it also starts or ends the hidden word.
    • Use all the segment clues to work out the answer. With Strict fit on (the default), a guess is only accepted if it still fits every clue so far; one that contradicts an earlier clue flashes a quick reason and is skipped. The host can switch Strict fit off in Settings to accept any real word.
    • The keyboard colors itself: a letter turns green once it has been green in any guess, yellow if it has been yellow (and never green), and gray if it has only ever been gray. Everything clears at the start of each new round.
    • 💡 unlimited hints suggest a word that fits the clues (never the answer). Difficulty (Normal/Medium/Hard/Random) sets how tricky the word itself is.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
