Starter word

On (default): one random word is placed on the board for free at the start of each round (worth no points) so chat has colors to read next to the number code. Off: every round starts on a blank board with just the number code. Takes effect from the next round; your choice is remembered.

Color shades

Choose how strong each color (green, yellow, blue, pink and gray) looks, in the tiles, the legend and the keyboard. Ten shades per color, from lightest to darkest (the middle one is the standard look). It applies right away - no new round needed - and every screen connected to this game changes together.

Win celebration

After a win, the leaderboard pops up automatically, then closes on its own. Auto-continue (above) always waits for this celebration to finish before starting the next round.

Strict fit

On (default): a guess must still fit the colors of every guess on the board, otherwise it is skipped with the message below. The clues are very precise, so only a handful of words can fit after the first guess or two. Off: any real word of the right length is accepted and colored, so chat can probe freely. Your choice is remembered and applies right away.

Auto-color keyboard keys

On (default): every key on the keyboard takes the color its letter has earned on the board. Off: the keys stay plain (neutral) - viewers only read the colors on the tiles. Applies right away on every connected screen and is remembered.

Guess rejection message

Shown briefly whenever Strict fit skips a guess.

    How to play

    • Guess the hidden word — any length you like, chosen in Settings. Unlimited guesses, anyone can play, anytime.
    • At the start of every round you get a number code above the board — one number per letter of the hidden word. Each number is the place that letter takes if the letters of the word were sorted alphabetically.
    • Example: for TELL the letters sort to E-L-L-T, so the code is 4 1 2 3 (T is 4th, E is 1st, and the two Ls are 2nd and 3rd, left to right).
    • Every guess is colored letter by letter: green right letter in the right spot   yellow the letter is in the word but in another spot   blue the letter is within 3 letters of the hidden letter of that spot (e.g. B is close to A–E)   pink meets both the yellow and the blue condition   gray the letter is not in the word.
    • Repeated letters are counted like Wordle: a letter is only yellow or pink as many times as the hidden word really contains it.
    • The keyboard colors itself: every key shows the best color its letter has earned in any guess this round (green, then pink, yellow, blue) - except that a letter confirmed gray (not in the word) always turns gray, even if it was blue before. The host can switch this off in Settings (Auto-color keyboard keys). Everything resets each new round.
    • A word already on the board is skipped. Strict fit is on by default, so only guesses that still fit every earlier color are accepted; the host can switch it off in Settings to accept any real word.
    • Scoring (Live): 1 point for every guess placed on the board, 5 points for the guess that solves the round.
    • 💡 unlimited hints suggest a word that best fits the code and the colors so far (never the answer). Difficulty (Normal/Medium/Hard/Random) sets how tricky the word itself is.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
