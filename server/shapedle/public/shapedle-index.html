After a win, the leaderboard pops up automatically, then closes on its own. Auto-continue (above) always waits for this celebration to finish before starting the next round.

Strict fit

On (default): a guess must still fit the colors of every guess on the board, otherwise it is skipped with the message below. The clues are very precise, so only a handful of words can fit after the first guess or two. Off: any real word of the right length is accepted and colored, so chat can probe freely.     How to play

    • Guess the hidden word — any length you like, chosen in Settings. Unlimited guesses, anyone can play, anytime.
    • At the start of every round a row of symbols (cute shapes, flags, professions, your viewers' profile pictures...) appears above the board. Each symbol stands for one letter of the hidden word, and the same letter always shows the same symbol (so two identical symbols mean a repeated letter).
    • Every guess is colored letter by letter: green the letter is correct and in the right spot   yellow the letter is in the word but in another spot   gray the letter is not in the word.
    • Repeated letters are counted like Wordle: a letter is only yellow as many times as the hidden word really contains it.
    • The keyboard colors itself: every key shows the best color its letter has earned in any guess this round (green, then yellow, then gray) so it is easy to see which letters are left to try. The host can switch this off in Settings (Auto-color keyboard keys). Everything resets each new round.
    • A word already on the board is skipped. Strict fit is on by default, so only guesses that repeat letters like the symbol row and still fit every earlier color are accepted; the host can switch it off in Settings to accept any real word.
    • Scoring (Live): 1 point for every guess placed on the board, 5 points for the guess that solves the round.
    • 💡 unlimited hints suggest a word that best fits the symbols and the colors so far (never the answer). Difficulty (Normal/Medium/Hard/Random) sets how tricky the word itself is.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
